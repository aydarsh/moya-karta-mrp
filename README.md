# Моя карта МРП

Русскоязычный навык для Codex помогает вести карту самонаблюдений по симптотермальному методу распознавания плодности. Вы сообщаете наблюдения, а агент заполняет Excel-карту, задаёт уточняющие вопросы по одному и объясняет разметку графика.

## Установка

Скопируйте сообщение и отправьте его в чат Codex:

> Установи мне навык «Моя карта МРП» по ссылке https://github.com/aydarsh/moya-karta-mrp

## Первая запись

После установки откройте в Codex папку для своих карт и напишите, например:

> Моя карта МРП, начнём новый цикл. Сегодня первый день, БТТ 36,55 °C, измерила в 7:10.

Агент создаст Excel-карту в выбранной папке и задаст следующий вопрос.
